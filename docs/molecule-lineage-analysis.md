# 分子实例谱系

分子实例谱系回答的是：从一个具体 Reaction Occurrence 的某个反应物或产物出发，携带所选锚点原子的分子在相邻 Reaction Occurrence 中如何改变。它用于观察单个分子的增长、拆分、合并、片段离去和结构往返，不是 Species 丰度曲线，也不自动给出反应机理。

## 身份与连续性

起点由以下证据共同确定：

- Reaction Occurrence 的稳定 `event_id`；
- 反应物或产物侧及该侧参与者序号；
- Analyzed Frame；
- 精确 Species、atom-ID 集合和分子内键集合。

向前查询只接受该精确分子实例第一次可解析的后续消费；向后查询采用对称规则。若最近的锚点原子事件不能唯一匹配当前 Species 与 atom-ID 集合，当前分支保守停止并记录截断原因，不跨过证据断点按同名 Species 拼接。

## 锚点与分支

默认锚点是起点分子的全部非氢原子。该规则要求轨迹自身提供 `element` 列，或用户在当前 Dataset Workspace 中确认完整的 Type → Element 映射；软件不会根据 SMILES 顺序猜测 atom ID 对应的元素。纯氢体系必须显式选择“全部原子”。用户也可以指定元素或 Atom IDs。

锚点规则只决定哪些分支继续展开：

- 拆分后，所有保留至少一个锚点原子的产物都继续；
- 合并后，保留锚点的产物继续，其他反应物作为上下文显示；
- 不带锚点的离去片段仍显示，但不自动扩展；
- 氢原子的变化始终保留在事件和键变化证据中，只是不因单独携带氢而延伸默认谱系。

## 原始视图与持久视图

原始视图保留查询范围内的全部 Reaction Occurrence。持久视图折叠 Fast Recrossing Episode：同一锚点原子集在窗口内返回完全相同的 Species、atom-ID 集合和分子内键集合。默认窗口为 5 个 Analyzed Frames。折叠只影响总览图；事件表、JSON 和 CSV 始终保留原始事件。

默认查询在起点前后各展开 3 次持久变化，最多保留 100 个分子节点。达到深度、节点数、关联歧义或连续性边界时，报告明确写出停止分支和原因。

## 结构变化标签与结论边界

单个事件只使用中性的结构标签：`merge`、`split`、`fragment gain`、`fragment loss`、`rearrangement`、`substitution/transfer`、`fast recrossing` 和 `complex`。增长或降解仅作为谱系末端相对起点的重原子规模汇总，不解释为反应机理、速率控制步骤或因果结论。

图用于总览。按时间排列的事件表和导出文件是审计依据；图中的事件节点和表格行都可用稳定 `event_id` 回到局部轨迹查看器。JSON/CSV 记录查询参数、来源签名、分子节点、事件、边、键变化、回穿段和截断原因。
