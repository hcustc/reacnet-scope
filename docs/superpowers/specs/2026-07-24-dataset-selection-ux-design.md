# 数据集选择与工作流状态优化设计

## 目标

第二阶段首先优化 ReacNet Scope 的数据导入体验，让用户以“选择
ReacNetGenerator 数据集”而不是“填写服务器目录和内部 base”的方式加载数据。
同时修复物种重新检索后界面仍保留旧物种、旧通道和旧事件的问题。

## 当前问题

当前数据导入需要依次完成：

1. 打开“管理数据”；
2. 打开服务器目录浏览器；
3. 逐级进入目录并选择当前目录；
4. 返回管理窗口后点击“扫描”；
5. 理解并选择“运行组（base）”；
6. 点击“应用”。

目录浏览器只展示文件夹，不提示哪些目录包含可加载数据。`base` 是输出文件的
公共前缀，例如 `rp3.lammpstrj`，属于内部解析概念，不应在只有一个候选数据集
时要求用户理解或操作。

物种工作流还有独立的状态问题：新检索结果仍可能保留上一轮表格的
`selected_rows=[0]`。当新结果同样只有第 0 行时，Dash 不会触发新的选择事件，
导致表格显示 CH3、内部状态仍为 H2。

## 采用方案

采用“数据集导向的服务器选择器”，保留现有服务器文件系统模型和允许根目录
安全边界。浏览器负责导航和发现数据集，管理窗口负责展示选择结果及准备状态。

不采用浏览器原生文件选择器，因为远程部署时它选择的是客户端文件，而服务端
无法直接读取这些路径。

## 数据集选择器

### 浏览与导航

选择器提供：

- 面包屑导航；
- 可编辑的当前路径；
- 返回上一级；
- 普通子目录列表；
- 最近使用的数据集；
- 当前目录的数据集发现结果。

所有输入路径继续通过现有 `validate_browse_path` 校验，并限制在
`REACNET_SCOPE_ALLOWED_ROOTS` 内。路径输入无效、越界、无权限或目录消失时，
在选择器内部显示错误，不覆盖当前已加载数据集。

### 数据集发现

扫描一个目录时，按 ReacNetGenerator 文件公共前缀聚合候选数据集。候选项至少
显示：

- 用户可读名称；
- 公共前缀；
- 已发现的核心文件；
- 文件完整度；
- 事件、轨迹和组成索引状态。

发现过程只检查文件名、文件存在性和索引元数据，不读取大型源文件内容。

### 选择规则

- 当前目录只有一个候选数据集：自动选中，不显示 base 控件。
- 当前目录有多个候选数据集：显示“选择数据集”列表，不显示“运行组”术语。
- 当前目录没有候选数据集：允许继续进入子目录，并明确提示“未发现
  ReacNetGenerator 数据集”。
- 用户也可以粘贴完整目录或数据集公共前缀；失去焦点或按 Enter 后自动发现。

### 应用流程

用户在选择器中点击候选数据集后：

1. 立即执行轻量状态扫描；
2. 展示数据集名称、核心文件和准备状态摘要；
3. 用户点击一次“加载数据集”完成应用。

不再要求单独点击“扫描”。管理窗口保留“刷新状态”，用于源文件或离线索引发生
变化后的显式刷新。

最近使用记录保存在当前浏览器的本地 `dcc.Store` 中，最多保留 10 项并按最近
加载时间排序；只保存目录和数据集公共前缀，不缓存源文件内容，也不写入服务端。
记录失效时显示为不可用，并允许从列表移除。

## 管理数据窗口

管理窗口顶部改为：

- 当前候选数据集摘要；
- “选择其他数据集”按钮；
- 手动路径输入作为高级/备用入口。

原“运行组（base）”字段从普通流程移除。多数据集目录中的候选选择由数据集
选择器承担。现有数据准备状态、复制命令和安全清理功能保持不变。

用户取消选择器或扫描失败时，管理窗口继续保留当前已加载数据集，避免误清空
工作流状态。

## 工作流选择重置

每次物种检索成功返回新结果时：

- 清空 `workflow-species-grid.selected_rows`；
- 清空候选物种选择；
- 清空通道和事件选择；
- 返回第 1 步；
- “使用此物种查看通道”保持禁用，直到用户明确选择新结果。

仅修改检索条件但尚未执行检索时，不清空当前工作流。检索失败时保留已加载
数据集，但清空本次无效的候选行，避免把旧行误认为新结果。

更换数据集时继续完全重置物种、通道、事件和验证视图；会话内属于旧数据集的
验证记录不显示在新数据集中。

## 组件边界

### 服务层

提供轻量的数据集发现接口，输入已验证目录，输出候选数据集描述符。该接口不
依赖 Dash 组件，也不读取大型 CSV、轨迹或 Route 内容。

### Dash 状态层

维护以下相互独立的状态：

- 浏览器当前位置；
- 最近使用的数据集；
- 当前候选数据集；
- 已应用的数据集；
- 工作流物种、通道和事件选择。

候选数据集只有在用户点击“加载数据集”后才替换已应用数据集。

### 展示层

目录浏览、数据集候选卡片和准备状态只消费服务层描述符。`base` 仍可作为内部
字段传递给现有 `scan_dataset`，但不直接显示为必填概念。

## 错误处理

- 越界路径：拒绝访问并说明允许根目录。
- 无权限目录：保留当前位置并标记不可访问项。
- 没有数据集：允许继续导航，不产生加载失败状态。
- 多候选数据集：要求用户选择，不擅自使用第一个候选。
- 候选在加载前消失：加载失败并保留原数据集。
- 索引未准备：允许加载数据集，在准备状态中给出对应离线命令。
- 最近记录失效：标记不可用，不自动删除其他记录。

## 测试与验收

### 服务测试

- 单数据集、多数据集和空目录发现；
- 候选公共前缀和文件完整度；
- 不打开事件 CSV、species、Route 或轨迹；
- 越界、无权限和路径消失；
- 最近记录中失效路径的处理。

### Dash 回调测试

- 打开选择器时从当前数据集或允许根目录开始；
- 路径输入、面包屑和上级导航；
- 单候选自动选中；
- 多候选要求明确选择；
- 选择候选后只需一次加载；
- 取消或失败时保留当前数据集；
- 新物种检索清空旧 `selected_rows` 和工作流选择。

### 真实数据验收

使用 `ref_data/rng-test-rp3-0523` 验证：

- 从允许根目录导航到 RP3 数据集；
- 直接识别 `rp3.lammpstrj`，不显示“运行组”；
- 一次确认完成加载；
- 显示事件、轨迹和组成准备状态；
- 从 H2 返回第 1 步检索 CH3 后，底部选择不再保留 H2；
- 选择 CH3 后能够进入其通道页面。

## 非目标

本次不实现：

- 上传客户端文件到服务器；
- 修改或移动 ReacNetGenerator 源文件；
- 自动运行离线索引构建；
- 在服务器允许根目录之外浏览；
- 全局项目数据库或多用户数据权限系统。
