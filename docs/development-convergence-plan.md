## 1. 完成目标

用户能够围绕已有 RNG 数据完成：

> 找到目标物种 → 查看丰度及直接生成/消耗通道 → 定位具体事件 → 检查局部轨迹和原子谱系 → 导出证据 → 比较不同来源。

本轮不以功能数量、页面美观或代码行数作为完成标准。以第 7 节固定真实案例的操作闭环、身份正确、状态可靠和数据读取有界作为标准。

普通导航收为五个工作区；内部工具可保留原页面 ID，避免为了导航合并立即重写全部布局和回调。

| 工作区 | 主入口 | 内部/辅助工具 |
| --- | --- | --- |
| 数据集 | 选择、来源信息、能力及准备任务 | 单位设置、派生索引维护 |
| 物种与趋势 | 物种检索、结构和时间演化 | 质量检索、元素分布 |
| 反应与事件 | 直接生成/消耗通道、事件列表 | 反应式查询、时间分布；路线工具另按下述冻结政策处理 |
| 轨迹与谱系 | 局部帧、键变化、原子谱系 | 事件包、必要的初始几何导出 |
| 对比 | 明确来源与目标映射后的比较 | 物种曲线、反应检出和已有重复统计 |

## 2. 范围政策

| 处置 | 本轮决定 |
| --- | --- |
| 继续完善 | 精确身份解释、直接通道、事件/轨迹交接、继续追踪分支、跨来源比较 |
| 合并入口 | 单/多来源时间演化、反应式/物种通道结果、各页面的数据来源选择 |
| 撤出普通界面 | 候选综合评分与能量 CSV 打分、通用 Fate 独立入口、未完成的连续支持控件、默认表观 k 设置 |
| 冻结扩展但保留现有核心 | Fate、表观 k、手工路径验证、候选路线研究、QC 交接扩展 |
| 保留最低必要能力 | 事件几何导出及其原子映射、单位、PBC、几何检查；实际使用的查看器导出 |
| 明确不做 | TS/IRC 自动化、量化调度平台、理论速率/主方程求解、自动机理评分、通用身份重建、重新检测反应 |

“撤出普通界面”意味着普通导航、数据集任务卡、跨工具按钮均不再推广这些工具。P1
曾保留兼容页面以完成迁移，P5 已删除这些页面及其专用回调；旧页面 ID 现在直接归一到所属
工作区，不自动运行分析。公共 CLI/API 与共用证据核心继续兼容保留，不另建可无限增长的
实验功能市场。

普通查询不得隐式计算 k 或调用冻结的评分服务。单纯隐藏分数但继续依靠同一综合分数决定默认“最佳路径”，不算完成收敛。现有候选研究实现先退出主线；本轮不重写其 ranker。将来恢复普通路线工具时，另立明确的排序/证据契约与验收，不沿用“最高分＝最好路线”的暗示。

科学身份、计量、事件连续性、删失、物理单位与来源检查不因 UI 收缩而改变。共用事件/分子连续性索引不随 Fate 页面一起删除。体积和 PBC 数据不随 k 设置一起删除。

## 3. 阶段与依赖

执行顺序：P0 → P1 → P2 → P3 → P4 → P5。每阶段交付后单独验收。P1 是首个可发布的收敛版本；P2–P4 只补真实任务已经证明需要的缺口。

### P0：建立可回退基线，固定范围

任务：

- **C01** 记录当前工作树已有修改、可运行环境、测试结果及当前页面/CLI/API 清单；保存可恢复的代码版本。不得把其他任务的修改当作本轮删除对象。
- **C02** 将第 2 节处置映射到具体导航、按钮、回调、服务、CLI、导出和测试。标明“隐藏/停止默认调用/兼容保留/以后删除”，不只做菜单清单。
- 实施范围调整时，同步设计基准的产品范围/导航/发布门槛；若替代已接受范围决策，以新的 ADR 记录替代关系，保留历史理由。CONTEXT 只在领域含义确有变化时修改。

主要位置：`navigation.py`、`app.py`、`callbacks.py`、服务门面、CLI parser、设计基准与有效 ADR。

验收：每个拟撤入口有依赖和保留策略；四个真实案例的源修订、参数及预期记录齐全。此前 543 项测试仅作历史参考，实际执行时重新记录基线。

停止条件：不借此阶段整理整个仓库或统一全部架构。

### P1：缩减普通产品表面

任务：

- **C03** 实施五工作区导航及相应任务入口，冻结工具退出普通推荐链路；处理旧 `page-store` 恢复和页面返回。
- **C04** 停止普通通道查询隐式触发速率相关操作，保留物理时间设置；撤下能量打分、未完成控件和“最佳路线”推广文案。QC 界面止于现有事件几何导出和必要检查。
- 把“缺证据”“需准备”“尚未验证”继续明确显示，不能通过藏按钮掩盖分析限制。

主要位置：Dash 导航、布局、回调与相关本地 CSS/JS。保留稳定控件 ID 或同时迁移其所有引用，不添加另一套 Current Dataset。

验收：

- 新会话、旧会话恢复、切换数据集、返回上页均无失效入口。
- 普通物种/通道查询不调用 k、候选评分、Fate 或 QC 预检；用回调边界测试核查。
- 主线无冻结功能的前置要求；大屏和窄屏实际浏览器走通。

停止条件：不实现新路线算法、不删除公共 API、不大拆全部 callbacks。

### P2：打通“身份 → 事件 → 轨迹”

任务：

- **C05** 在目标详情中说明 RNG Species 标签、来源设置及原始分子证据的关系。可取得的 miso/HMM/采样信息显示来源，缺失则显示未知；不推测配置。
- **C06** 打通选中精确 Species → 通道 → event ID → 局部帧 → 证据导出，并提供可追溯返回。记录最小事件书签：数据集身份、源修订、事件身份和展示窗口；恢复时重新验证。
- 原始键结构仅对有界帧/实例核查。没有可用索引时给出准备要求，不以 UI 点击触发全量 HDF5 扫描；本轮不构造另一套 Species 身份体系。

主要位置：分析/证据服务、事件/分子证据读取、物种/事件/轨迹回调。按改动使用 analysis-contracts、evidence-indexing 与 dash-workflows 技能。

验收：案例 A、B；书签遇到源修订变化拒绝复用旧结果；失败保留当前数据集，切换清空旧结果；相同分子式的不同结构不会错传。

停止条件：不新增全轨迹同构搜索、身份重建或第二套成键检测。

### P3：让已有分子谱系可以完成真实追踪

任务：

- **C07** 将已有分段查询能力转为“从选中分支继续追踪”。继续追踪绑定 Molecule Instance、锚点、方向、源修订与预算，合并显示时按稳定身份去重。用户界面统一称为“继续追踪分支”。
- **C08** 提供分支摘要、明确停止原因、已查范围和事件/轨迹入口；保留分裂、重并、离去片段和原始事件。每次继续追踪由用户触发，先保持既有服务预算；不做自动无限追踪。
- 继续追踪失败不覆盖已完成片段；切换数据集后迟到结果不进入新上下文。

主要位置：`molecule_lineage.py`、证据服务、谱系布局/回调；如需新结果字段，同步版本和导出契约。

验收：案例 C；跨分段重复事件不重复累计，分裂/重并没有被压成虚假直线；达到预算显示未完成而非无上游。固定两种数据规模检查局部读取范围和内存，不用提高预算掩盖全量扫描。

停止条件：不顺带实现通用 Fate、自动主路径排名或完整 Continuous MD Support 平台。

### P4：合并比较流程，先保证可比性

任务：

- **C09** 统一来源记录和逐来源目标选择；单源时间演化与对比复用输入规范和核心服务，避免另起一套曲线/导出计算。
- **C10** 展示模型迭代、条件、重复、RNG 处理与身份口径、物理时间是否可比。目录名推断只能作为待确认信息；用户选中多个数据集不改变 Current Dataset。
- 优先完成精确目标曲线、反应检出和来源导出。未知项不补默认事实；网络级证据和分子时序证据分层显示。不新增跨来源自动结构归一化器。

主要位置：`species_compare.py`、`batch_compare.py`、相关服务、时间演化与批量对比 UI。

验收：案例 D；缺目标、有效零值、缺索引分别报告；旧数据无 timed molecular evidence 时仍可做支持的比较，但不能输出连续路径结论。未确认物理时间不画伪对齐物理时间曲线。

停止条件：不新增主机理显著性排名、通用报表平台或更多归一化模型。

### P5：移除已退役 UI，完成收敛验收

任务：

- **C11** 清理 P1 的冻结页面挂载、无人引用的回调、控件、CSS/JS 和重复输入组件。先检查 Python/JS/测试/CLI/API 引用；共享函数不能按页面目录整块删除。
- 公共 CLI/API、已有 JSON/CSV 字段本轮默认兼容保留。确需删除时列出替代入口、迁移方式和版本边界，再同步契约；不得静默改变旧字段含义。冻结核心仅修安全、数据正确性与主线兼容问题。
- **C12** 完成全量测试、浏览器主线验收和四个真实案例；更新使用说明、已知限制及本轮交付清单。

验收：普通主线不再挂载退役工具的控件和轮询；旧页面恢复能安全回到所属工作区；C01–C12 均有验证记录。没有浏览器/代表性数据时，该项明确未验收，不能凭单测宣布完成。

停止条件：不为减少代码行数而重写服务层、不重做查看器、不顺手增加功能。

## 4. 第一批开工任务

首批只做 C01–C04，交付可运行的五工作区版本：

1. 固定当前版本与功能依赖清单。
2. 同步本轮范围决策及兼容政策。
3. 调整导航、任务卡、返回入口和旧会话恢复。
4. 撤下评分/能量导入、未完成控件、Fate 普通入口，确认主线不隐式调用冻结分析。
5. 执行定向测试、全量回归和浏览器验收。

完成后再进入身份核查和谱系改善；不能边收菜单边启动新的高级分析开发。

## 5. 每批提交的拆分方式

每个 C 任务按可独立评审的变更组织，按需要拆成：范围/契约说明；服务变化与必要测试；UI 接线；死代码清理。不是要求机械生成四个提交。

保留行为的机械搬移与科学语义修改分开。每批记录影响入口、真实验证结果、未验收项和回退方法。代码回退不删除 RNG 原始工件；派生索引若发生 schema 变化，另提供版本迁移/重建说明，不能靠回滚 Python 文件假定索引兼容。

## 6. 验证安排

遵循[验证指南](agents/testing.md)：

- P1：Dash smoke、dataset selection/switch、capability；浏览器验证新旧会话与大/窄屏。
- P2：上述测试，加事件索引、time axis、事件包/导出及受影响的身份反例。
- P3：molecule lineage、在线索引契约、源修订与迟到结果；两个规模点的局部读取与内存记录。
- P4：species compare、batch compare、species evolution/time axis 与对应 Dash 链路。
- 跨模块、公共契约或依赖变化运行 `uv run --locked pytest -q`；文档任务只检查内容和链接。
- 不为纯样式新增逐字快照测试，不把现有断言删掉来迁就违反契约的新行为。

执行前把来源路径、修订、处理参数、查询参数与预算记录到本轮验收记录；源版本变化时先重新核实，下面的计数不能盲当所有版本的常量。

| 案例 | 已有参考 | 验收目标 |
| --- | --- | --- |
| A：目标标签与原始结构 | 本地 `analysis_outputs/chlorocyclopentadienone_20260918/miso_assessment.md` | 展示已核实的代表标签/原始键结构差异与来源；不把标签未命中直接说成真实结构不存在 |
| B：目标生成事件 | 本地 `analysis_outputs/target_generation_20260918/report.md` | 固定来源上复核 19 条生成 Reaction Type、269 条 matched 记录与四组碳集合，并可下钻；不把它们叫作独立实验或正式 episode 数 |
| C：分裂重并与继续追踪分支 | 本地 `analysis_outputs/chlorocyclopentadienone_20260918/iteration_comparison/report.md` | 保留分支、碳片段分离再合并；固定预算下可继续查询并明确未完成分支，不强求追到终点 |

## 8. 完成与停止条件

本轮完成需同时满足：普通导航五工作区；主线无评分/Fate/k/QC 前置要求；四案例具备可复现操作与导出；身份、单位、来源修订及失败状态正确；退役 UI 已清理；测试、浏览器及真实案例验收记录齐全。

本轮不承诺全部高级能力产品化，也不承诺由轨迹证明唯一机理。冻结功能只有在出现明确研究问题、可取得证据、重复使用场景和独立验收样例后才重新立项；不因“已经写了一半”恢复开发。
