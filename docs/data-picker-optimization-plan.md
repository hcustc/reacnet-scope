# 数据选择器优化方案

状态：历史方案已实施；用户后续明确以 RNG 输出文件夹为导入对象，主流程已由 [ADR-0024](adr/0024-import-rng-output-folders.md) 替代。以下保留设计与验证记录。

## 目标与边界

数据与软件同机运行，浏览器选择运行机器可访问的文件。普通路径为“浏览 → 勾选文件 → 开始分析”，保留跨目录选择、只读原始文件及两阶段数据集切换。目录只是浏览位置，不成为数据集边界。不恢复上传或增加部署服务。

## 已确认的问题

- 右侧逐文件卡片、路径、输入框和独占一行的移除操作占用过多高度；外层 grid 随内容增高，中间浏览区被动拉长。
- `selection_display` 在多组或无效组时强制显示所有归组输入框，与未勾选的“调整归组”控件不一致。
- 浏览位置与最近使用/已选草稿分别更新，因此可能出现右侧已有数据、中间却没有打开任何位置的状态。
- 勾选后还要点击“添加所选”，形成两套选择状态；跨目录追加时不易判断哪些已经加入。
- 禁用分析时显示通用说明，没有直接指出当前阻塞及恢复操作。
- 文件名截断后缺少足够辨识上下文，常驻路径却挤占了主要内容。

当前工作区的 `artifact_role` 已将 `trajectory.lammpstrj` 及其 `.species`、`.reactionabcd`、`.timeline.h5` 输出统一为建议组 `trajectory`。截图中分为两组的确切原因尚未确定，需检查实际运行版本、已有集合标签及草稿 assignments；不能推定文件已证实来自同一次运行，也不能覆盖用户明确归组。

## 交互设计

### 主流程

1. 进入时恢复上次仍可访问的浏览位置；没有记录时打开一个有效默认位置。路径不可用时显示就地恢复动作，不留下无说明的空表。
2. 目录与文件使用统一列表：目录行打开目录，文件行勾选/取消。勾选直接更新草稿，取消勾选只移除对应文件；切换目录保留其他目录的选择。
3. 普通单组自动成为待分析组。底部显示所选组和文件数，点击“开始分析”才验证与提交切换。
4. 点击最近记录恢复对应文件集合，并定位到上次来源目录或一个有效源文件目录；来源跨目录时不跳转内部 collections 工作区，也不暗示只有当前目录中的文件属于集合。

移除普通流程的“添加所选”按钮。批量添加目录、包含子目录、粘贴多路径保留在次要菜单，扫描继续支持取消和上限提示。明确区分当前可见结果与未枚举文件，过滤不改变已有选择。

### 已选数据

右侧以数据集摘要为主：名称、文件数、紧凑的文件角色/状态列表。单组不显示单选框、不逐文件显示归组输入框。文件清单可展开，每行名称加移除按钮，完整路径可通过详情查看和复制；跨目录同名文件显示最短可区分父路径。

多组时显示紧凑组列表，明确选中本次分析组；“调整归组”打开独立编辑区域，通过移动文件到已有组或新建组调整，支持批量移动，不要求手打重复组名。只有显式编辑时才进入编辑模式。

异常归属项集中在“待确认”区域，提供具体操作，例如“将此轨迹关联到 trajectory”；用户确认后才应用关联。同角色多个来源明确选择/拆组，不能按文件名或目录静默选择来源。缺坐标等可选证据不阻塞其他分析能力。

### 布局

- 顶部：标题、当前路径；上一级、位置切换、名称过滤。
- 左侧：紧凑位置列表与最近记录，宽度约 160–200 px。
- 中间：占据剩余空间的文件列表，名称为主，类型与大小对齐。
- 右侧：宽度约 300–360 px 的待分析摘要，仅显示必要信息。
- 底部：数量/状态、取消、开始分析；准备任务入口移出主操作栏。

桌面选择器高度由视口剩余高度决定，头尾固定，浏览列表和已选清单各自滚动。右侧条目数量不能拉高整个页面，页脚不覆盖最后一项。断点依据实际工作区宽度，包含应用导航占用和浏览器缩放。空间不足时，位置折叠为菜单，已选数据折叠为可展开摘要，避免三栏逐块堆成长页面。

## 状态与文案

- 浏览中：列表局部加载；已有草稿保持可见。
- 空目录：仅“没有可用的 RNG 文件”，保留上一级/换位置动作。
- 未选择：主按钮禁用，摘要提示“选择要分析的文件”。
- 单一有效组：自动选中，显示真实可分析能力；准备任务沿用现有流程。
- 多组：提示“选择本次分析的数据集”，不将多组本身视为错误。
- 冲突：具体到文件/角色，提供选择来源或调整归属；不强制展开所有表单。
- 缺失/无权限：指出受影响项，可定位、替换或移除；保留其他草稿。
- 验证中：防止重复提交，可取消；失败和迟到结果不改变当前数据集。

5. 验证用户操作、状态竞态与真实浏览器呈现，再交付。

## 验收标准

- 截图四文件在无显式覆盖的情况下建议为一组；只有文件命名建议，不宣称同次运行已被科学验证。用户明确拆组仍保留；旧状态异常有可操作的恢复路径。
- 普通操作不需要编辑归组、输入内部标识或点击额外“添加”按钮。
- 勾选、跨目录追加、取消勾选、恢复最近记录、离开再返回的结果符合一致草稿语义；页面刷新/回调迟到不清空新选择。
- 用 4/50/500 个条目及长中文名、同名跨目录、缺失文件验收；超过现有限制明确报告，不假装完整。
- 1366×768、1920×1080、540 px 窄屏及 125%/150% 缩放检查：主操作可见、内容不遮挡、不横向溢出、滚动区域明确。
- 键盘可浏览/勾选/取消/提交，焦点可见；完整路径不能只靠鼠标悬停获取。
- 浏览器分别验证无选择、单组、多组、冲突、权限错误、验证失败和取消；回调测试覆盖上述时序。小 fixture 不代表大型真实数据或跨平台验收完成。

## 实施与验证记录

- 已实现勾选直接更新草稿、跨目录/筛选/分页保留选择；每页 50 项，名称筛选覆盖当前已枚举列表，枚举达到上限仍明确报告。
