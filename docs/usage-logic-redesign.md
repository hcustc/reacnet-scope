# ReacNet Scope 使用逻辑

## 设计原则

ReacNet Scope 采用工具箱结构：

- 通用能力保持小而独立，可以单独使用。
- 自动化能力单独分组，不与基础检索混在一起。
- 页面顶部始终展开全部功能入口；分组只表达类别，不使用下拉菜单。
- 页面内部只保留标题、数据状态和直接操作区域，不再用卡片包裹完整功能。
- 页面之间只传递必要的物种、反应或事件上下文，不复制分析算法。

## 顶部导航

所有入口均直接可见，组间只用分隔关系，不设置需要再次展开的菜单。

| 分组 | 功能 |
| --- | --- |
| 通用工具 | 物种检索、反应式检索、时间演化、事件与轨迹 |
| 自动分析 | 中间体筛选、候选路径、组成演化 |

默认进入“物种检索”，不再设置分析首页或强制流程。批量对比属于数据集管理，
从“管理数据”进入，不占用顶部工具栏。

## 功能边界

| 功能 | 主要职责 |
| --- | --- |
| 物种检索 | 按分子式、SMILES 或质量定位物种 |
| 反应式检索 | 按反应物和产物组合查找反应 |
| 时间演化 | 查看一个或多个物种的丰度曲线 |
| 事件与轨迹 | 检索具体事件并查看局部轨迹 |
| 中间体筛选 | 按丰度、寿命和通量自动筛选候选 |
| 候选路径 | 从指定物种自动扩展有界路径 |
| 组成演化 | 按 C/O/Cl 条件筛选并查看组成变化 |
| 批量对比 | 从数据管理中选择多组模拟结果进行比较 |

## 跨工具衔接

工具保持独立，但允许以下快捷交接：

- 物种 → 反应式检索中的生成/消耗通道、时间演化、候选路径、事件与轨迹。
- 反应 → 候选路径、事件与轨迹。
- 中间体候选 → 候选路径、时间演化。
- 候选路径反应 → 事件与轨迹。

这些交接只负责填充目标和切换页面，分析逻辑仍由目标工具统一执行。

## 去重原则

- 页面名称和导航分组只在 `navigation.py` 定义。
- 通用分析逻辑集中在 `services.py` 和核心模块。
- 自动分析调用通用服务，不重新实现物种、反应或事件检索。
- 物种核查统一沿“物种 → 生成/消耗通道 → 通道事件”展开，不再维护独立核验页面。
- “高级”仅用于少用参数，不再作为完整功能入口。
