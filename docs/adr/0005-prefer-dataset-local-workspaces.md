# Prefer dataset-local workspaces with a central fallback

ReacNet Scope is local-first and remote-compatible. For a writable local dataset, its derived indexes, checkpoints, task records, and dataset settings belong in a sidecar `.reacnet-scope/` workspace so that the dataset remains portable and its generated state is easy to inspect or remove. When the source location is read-only, shared, or remotely mounted, ReacNet Scope falls back without configuration to its platform-standard user workspace; an administrator may explicitly override that location with centralized storage. Dataset identity is recorded in the sidecar manifest rather than derived only from an absolute path: moving a directory preserves its identity, while finding the same identity at two live paths creates an independent identity for the copy. ReacNet Scope never modifies ReacNetGenerator source artifacts, never requires a cache environment variable for local startup, and always exposes the actual workspace location in the UI.
