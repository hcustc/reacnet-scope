# ADR-0019：分开记录锚点连续性、原子来源与完整反应计量

- 状态：Accepted
- 日期：2026-09-21
- 补充：[ADR-0018](0018-explore-segment-occurrence-lineage.md)

## 问题

双分子与 merge 事件本身不构成路径不合理的证据。一个携带连续碳骨架的投影可以失去
原有 Cl，随后加入相同或不同的 Cl。仅检查最终原子集合会把“重新出现”误当作全程连续。
只显示主投影又会隐藏 O₂ 等共同反应物，丢失计量与来源。

## 决策

Explorer 默认全部起点原子为锚点，并支持按元素、非氢原子和显式 Atom IDs 选择。
元素来自显式输入或精确索引帧中的可靠映射，不从 Species/分子式排列推断。
报告分别保存 root atom set、anchor policy、anchor set 与元素来源；连续锚点逐步取交集。
不按双分子、merge、返回或骨架保留比例过滤事件。

每个事件保留全部输入/输出、带重复系数的精确 Species 计量、来源到去向的原子转移。
单条路径保留这些上下文，另行报告离开、加入、原始原子返回与外来原子加入。
只有已展开具体图上的严格连续传递才证明返回原子的离开期间支路；未展开支路明确未解析。
原子身份重现不是该路径连续性的恢复。

对所选路径报告多事件精确状态返回和仅拓扑返回。返回匹配要求相同 Atom IDs，精确匹配
还要求相同 Species 和键集合；拓扑匹配忽略键级。时间报告 transition 差值，不设删除窗口。
该注释不判定噪声、净生成次数、能垒、动力学贡献或主机理。

Explorer JSON 升级为 v2；segment 单段 retained/lost/gained 参考所选锚点。
旧报告需重新打开起点，底层 segment 索引版本 1 不变。导出重读当前索引并校验源修订。
旧 `molecule-lineage/v2` 兼容工具及其显式折叠规则不受本决策更改。

## 取舍

采用有界展开后的证据标注，避免为解释一个返回而在线扫描全轨迹。缺少支路或元素映射
会使部分注释未完成，但不会伪造来源、删除已观测事件或把候选物种路径当成具体历史。
