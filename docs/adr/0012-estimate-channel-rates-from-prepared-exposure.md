# Estimate Channel Rates from Prepared Exposure

Direct Reaction Channel tables may report physical event frequency and an Apparent Rate Constant Estimate only when the current dataset supplies exact Reaction Occurrences, confirmed physical time, and aligned Species Abundance Evidence. Second-order estimates additionally require confirmed Å coordinates and simulation-box volumes prepared in the Trajectory index. Forward and reverse directions are estimated independently from occurrence counts; TP and net TP remain descriptive network statistics and never substitute for the numerator.

The MVP adopts an explicitly reported stoichiometric mass-action model for first- and second-order Reaction Types. Exposure uses the left endpoint of each Transition. Repeated reactants use the falling factorial, so `2 A` contributes `n_A(n_A-1)` under the deterministic mass-action convention. Every result carries the observation window, event count, exposure, unit, model, and an exact Poisson 95% interval and is labelled “apparent k”.

Trajectory preparation records per-frame simulation-box volume so online channel queries consume only published indexes. When the trajectory is not colocated with the other ReacNetGenerator artifacts, an explicit path association is stored in the Dataset Workspace and takes precedence over same-directory discovery; ReacNet Scope does not move or modify the source trajectory. Missing, stale, unconfirmed, higher-order, or misaligned evidence disables the estimate independently for each direction while preserving TP display and a concrete, categorized reason.
