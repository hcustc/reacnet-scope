# 使用 ReacNet Scope 分析数据

先读 [领域词汇](../../../CONTEXT.md)，按问题读取
[设计基准](../../../docs/software-design-baseline.md) 的对应分析章节。
本技能指导分析操作与解释，不另定义 Species、Candidate Path 或 Event Path 契约。
优先复用当前 Python API、CLI 和已准备索引；先检查实际接口与能力，不能照搬旧命令。

## 保持用户的问题

先分清用户要确认物种出现、追踪一个实例、比较整体反应行为，还是评价势函数准确性。
用户问“新模型是否更好”时，不把任务缩成追一条路径；单个实例只用于解释整体差异。
软件实现问题与使用口径问题分开判断，不能把一次检索误用直接列为产品缺陷。

## 目标结构与 miso

- 从图片或名称明确目标连接关系；分子式和结构相似性用于发现候选代表，不能自动代替
  精确身份。已知存在 miso 合并时，先查对应连接骨架及其代表结构，不只精确匹配原图
  SMILES。记录实际用于查询的源 Species；需要时让用户确认对应关系。
- 在常见 RNG 语义下，`miso=0` 保留键级差异，`miso=1` 合并相同元素/原子连接关系下的
  不同键级结构；后者不合并开环与闭环。涉及具体数据结论时核实运行版本与参数，不从
  输出长相反推参数，也不默认新旧文件使用了不同参数。
- 区分“精确名称未命中”“对应代表或连接骨架未检出”“原始键级证据未记录目标”。
  代表标签不等于该组每一帧的精确键结构；同样，单帧被赋予目标键级也不证明稳定产物。
- 原始证据保留键级变化，不等于合并后的分析把它计为独立反应。键级往返可能包含识别
  抖动，也可能涉及实际变化；不能仅凭往返就认定伪反应或软件缺陷。
- 不因名称零命中就建议全量改用 `miso=0`：它可能增加键级碎片化。先看现有索引和源
  工件能否回答问题。若 HDF5 确实保留分子原子、键级及占有区间，可按需做有界、只读的
  离线核查；没有这些字段时说明缺口。坐标不能替代 RNG 重新认定反应。
- 核查中明确 atom ID 的基数/映射、帧与 timestep 的关系及物理单位。分子定义可在多个
  不连续区间重现，定义数、分子·帧数、独立生成次数与连续寿命不能混用。

## 路线与实际分子历史

- 仅有聚合反应文件时，结果称为聚合网络连接；不能称为满足正式证据条件的 Candidate
  或实际连续 MD 路径。最短连接、较高 TP 均不能替代实例验证或主通道份额统计。
- 有事件和分子证据时，按请求使用谱系或路径分析，保留完整共反应物、副产物、方向、
  原子对应及查询限制。各步骤独立有记录，不代表同一个分子依次完成。
- 区分“目标骨架形成”与“该骨架某帧呈现目标键级”。忽略键级的比较是显式分组视图，
  不能悄悄改写源 Species 身份或声称实现了新的正式分析契约。
- 谱系发生分裂后重并、开闭环往返或经过加合物时，明确这是带分支的历史。摘要可选
  关键节点，但要说明省略了什么，不能把节点压成直接相邻的基元步骤。
- 不把一代模型的网络例子与另一代的具体事件历史当作对等证据，宣布生成机理改变。

## 多来源与模型比较

- 多来源比较首先是按同一查询口径并排展示。使用者负责实验可比性的判断；只记录本次
  结论所需的来源标识、目标对应、时间范围和限制，不把普通比较扩成实验管理系统或
  强制元数据问卷。目录中的不同 RNG 处理产物不自动视为独立 MD 重复。
- 先确认用户选的是哪份产物，再核对会影响解释的差异；不要随意选择一个 reactionabcd
  代表整次运行。多个来源可能以不同 SMILES 代表目标，需要保留逐来源对应。
- 比较行为优先看丰度曲线、元素去向、产物分布以及目标骨架占有情况；TP 只按其记录
  含义报告，不当作产率、速率、独立分子数或“模型更好”的分数。
- “行为不同”不等于“更准确”。评价准确性需要适用的独立实验或量化参考；若评估方案
  包含 DFT，应让两代模型预测同一批、涵盖双方采样的构型，并核对参考独立性。
  多来源不自动等于独立重复；不足以推断的主通道或模型优劣要明确留白。
- 用户只要求分析已有数据时，先交付已支持的比较及具体缺口；不要默认转成全量 RNG
  重跑、新 MD、DFT 或软件开发。确需扩展时说明它能解决哪个尚未回答的问题。

## 交付

先用直白语言回答“发现了什么、因此能说明什么”。对比表使用同一口径，给少量关键
证据与可追溯结果链接；不要堆反复免责声明或用技术细节掩盖尚无结论。
发现先前解释错误时明确更正并更新相关报告，而不是继续叠加不兼容的解释。

需要修改软件时，再按范围使用
[分析契约](../reacnet-analysis-contracts/SKILL.md)、
[证据索引](../reacnet-evidence-indexing/SKILL.md) 或
[Dash 工作流](../reacnet-dash-workflows/SKILL.md)；使用本技能本身不扩大任务范围。
